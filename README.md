# Inteligencia-Artificial-Scikit-learn-y-PyCaret-
Estudio comparativo e implementación práctica de modelos de Machine Learning utilizando tecnologías líderes en la industria (Scikit-learn y PyCaret). Este proyecto explora la eficiencia, escalabilidad y viabilidad de diferentes enfoques de Inteligencia Artificial para la resolución de problemas de negocio mediante prototipado rápido
