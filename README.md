# Applied AI & Machine Learning Prototyping 

Estudio comparativo e implementación práctica de modelos de Machine Learning utilizando tecnologías líderes en la industria (Scikit-learn y PyCaret). Este proyecto explora la eficiencia, escalabilidad y viabilidad de diferentes enfoques de Inteligencia Artificial para la resolución de problemas de negocio mediante prototipado rápido.

## Enfoque Tecnológico y Casos de Uso

El proyecto se centra en la evaluación técnica de herramientas de modelado de datos, contrastando el desarrollo tradicional de *pipelines* de Machine Learning frente a soluciones automatizadas (AutoML).

*   **Implementación con Scikit-Learn:** Desarrollo manual y control granular de algoritmos de Machine Learning. Diseño de *pipelines* personalizados para el preprocesamiento de datos, selección de características, entrenamiento de modelos y validación de métricas.
*   **Prototipado Rápido con PyCaret (AutoML):** Evaluación de entornos de *Low-Code Machine Learning* para acelerar el ciclo de vida del desarrollo. Automatización del entrenamiento comparativo de múltiples modelos simultáneamente y optimización de hiperparámetros.
*   **Análisis de Rendimiento:** Comparativa técnica entre ambas tecnologías basada en la velocidad de iteración, la curva de aprendizaje, la facilidad de despliegue (MLOps) y la precisión de los modelos generados.

## Aspectos Técnicos Destacados

*   **Ingeniería de Datos:** Técnicas de limpieza, imputación de valores nulos y codificación de variables categóricas.
*   **Evaluación de Modelos:** Análisis de resultados mediante métricas estándar de clasificación y regresión (Accuracy, AUC, RMSE, etc.) y matrices de confusión.
*   **Visión MLOps:** Enfoque orientado a la productivización de modelos y a la selección de la herramienta adecuada en función de los requisitos de tiempo y recursos del proyecto.

## Stack Tecnológico
*   **Lenguaje:** Python
*   **Librerías Core:** Scikit-learn, PyCaret, Pandas, NumPy.
*   **Entorno:** Jupyter Notebooks / Google Colab para análisis exploratorio y documentación interactiva.

## Estructura del Repositorio
El repositorio incluye los cuadernos de código con las implementaciones prácticas, los *datasets* de prueba utilizados y la memoria técnica detallando las conclusiones obtenidas de la comparativa entre la programación manual y el uso de frameworks AutoML.
